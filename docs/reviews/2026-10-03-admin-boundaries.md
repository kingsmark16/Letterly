## Limits

Authentication provider behavior and live database transactions are not re-proven by this fixture suite. Seven database dependent integration cases remain skipped without the configured test environment. No live administrator command, mutation, retention purge, migration, or seed ran. Retention lifecycle integration remains infrastructure, and existing moderation transaction dependent policies are unchanged. New template version coexistence remains a separate incomplete requirement of the overall restructuring.
