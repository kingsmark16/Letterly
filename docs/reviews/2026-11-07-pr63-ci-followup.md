# PR 63 CI followup

The first full CI run passed the build, container verification, workspace unit tests, API tests, and browser smoke tests. Its fixture suite reported 294 passes, two skips, and 16 failures. Six failures were older light palette expectations, four were insufficient contrast in landing empty and error headings, and six exceeded the unchanged editor CSS budgets.

The landing palette now maps canonical shared color properties as well as the legacy aliases. Shared Status headings and legal dialog chrome therefore use the requested dark theme with readable text. Presentation assertions now expect the approved burgundy palette and existing four pixel landing focus offset. Navigation, keyboard actions, dialog focus return, and recovery assertions remain in place.

The build combined the illustration stylesheet with shared route CSS, adding it to editor responses. Loading LetterStillLife through a default SSR dynamic boundary isolates its 7,220 byte stylesheet while retaining server markup, static artwork, and no JavaScript rendering. Moving individual utility styles did not resolve the budget and was reverted. Historical CSS and JavaScript baselines were not changed.

The targeted followup passed 23 browser cases with one hover test skipped on touch. Editor overview and settings CSS measured 449,384 bytes, below the existing 478,509.9 byte budget; editor content measured 468,955 bytes, below its 500,193.1 byte budget.

A broader Chromium, Firefox, and WebKit check identified additional browser differences before merging. Font readiness can remain unresolved in Firefox with JavaScript disabled, so category navigation now waits for document load and asserts native URLs and card counts without waiting on fonts. Interactive growth navigation waits for hydration, and the lazy canvas fallback check explicitly brings the canvas into view before selecting a scene. WebKit's default Tab behavior skipped implicit links; the skip link now has an explicit zero tab index, preserving its position in keyboard order. Short authentication layouts reduce padding and give provider labels more width to prevent loaded fonts from expanding buttons beyond the viewport. The focused WebKit skip link regression passed after this change.

The focused cross engine rerun passed 35 of 36 cases; the remaining long gallery pagination case intermittently missed a pointer click while entrance motion and scrolling overlapped. The data pagination test now selects system reduced motion, while the separate motion suite retains animated pointer and GPU checks. The final pagination and skip link rerun passed all 12 cases across Chromium, Firefox, and WebKit at both configured widths. No behavior assertions or browser projects were removed. Temporary diagnostic logging was removed before committing.
