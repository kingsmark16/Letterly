# Category browsing within the landing gallery

Landing category controls now target root query URLs with `#templates`, rather than opening `/templates/[categoryKey]`. The selected category has a visible underline and `aria-current`. Changing category clears cursor state, All categories resets the filter, and browser back restores the previous selection. Preview and Create draft retain the API-provided current version identity and their existing navigation and dialog owners.

The landing reader now loads active category metadata and one 20-item template page in parallel. This replaces the four-family-per-category overview preview, so every active design is reachable through inline Previous designs and Next designs links. Reads remain server-side, uncached, validated, and bounded by the existing API contract. There is no per-category request fan-out or unbounded fetch-all loop. Category and paging links disable speculative prefetching. Existing workspace browse routes and the overview API remain available to their existing callers; landing controls no longer navigate to them.

The gallery effect boundary remounts when its result set changes and refreshes scroll-trigger positions. That cleans up the previous card timelines and GPU resources and binds the shared border effect to the new cards. Empty filtered categories have specific recovery copy. Fixture-only navigation preserves the fixture selector, and a gated growth scenario exercises the real fixture API's cursor validation beyond the preview limit. No production categories or templates were added.

Nine server catalog reader tests passed. Of the initial 50 desktop/mobile browser cases, 46 passed, including rendering, accessibility, preview behavior, animation, GPU fallbacks, and all four landing performance surfaces. New navigation checks were synchronized to completed URL/selected-state changes; targeted reruns passed category switching, browser back, and traversal of all 25 filtered growth fixtures. No-JavaScript keyboard navigation passed on desktop and mobile; a separate manual browser check also verified native mouse navigation without JavaScript. The headless no-JavaScript pointer action wait was replaced with native keyboard activation in that test. Production build and TypeScript compilation passed. The selected Confession gallery was visually inspected on the root route. Validation used installed Node 26; supported Node 24 CI remains pending.
