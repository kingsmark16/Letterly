# Interactive How Letterly works guide

The four-column instruction strip is now a guided stationery illustration. The four original titles and descriptions remain server-rendered in an ordered list. Hover, keyboard focus, Enter, and tap select the corresponding artwork: two design cards, a letter and pen, a phone preview, and an envelope ready to share. Native anchors keep every instruction reachable without JavaScript. No real editor, preview, or publishing operation is triggered by the explanatory artwork.

GSAP handles finite scene transitions and measured SVG ink strokes. Rapid selection reverts the previous scoped animation before drawing the current scene. The selected link has `aria-current="step"`, visible keyboard focus, and a caption that announces the current illustration. The phone layout places the artwork above a two-column step selector; all four descriptions stay visible.

A native WebGL field provides a metallic orbit, a thread of light, and restrained sparks. Its phase interpolates toward the selected step without rebuilding the GPU program; pointer input also moves the field. It shares the existing canvas lifecycle, caps output at 350,000 pixels and 30 frames per second, initializes only when visible, settles when idle, suspends offscreen and in hidden tabs, and disposes resources on cleanup. Reduced motion retains instant step selection with finished static artwork. Missing WebGL retains the SVG illustrations and instructions. Existing envelope and wax-seal SVG assets are reused, with no new dependencies, fonts, or raster downloads.

Validation: 32 targeted desktop/mobile browser checks passed in the initial run, including the new scene/ink interaction, rapid selection, selected GPU phase, frame settlement, reduced motion, missing WebGL, automated accessibility, and the unchanged performance budget. A misplaced no-JavaScript assertion in the responsive test was moved to its intended test, then all four targeted responsive/no-JavaScript cases passed. A separate touch-browser check selected the final step at 375 pixels without horizontal overflow. All four desktop scenes and the phone layout were visually inspected. Production build and TypeScript compilation passed. Validation used installed Node 26; supported Node 24 CI remains pending.
