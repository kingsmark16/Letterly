These checks cover the published subpath contract; the package intentionally has no root barrel export.

## Run evidence and limits

The latest complete shared UI run recorded before this report passed 444 cases with 30 intentional credential skips at `308a90a`. Application source is unchanged by the later test-only contrast commits. A fresh 474-case run reached all Chromium and WebKit cases. Its Firefox projects failed before page creation: 77 cases per viewport failed with `browserContext.newPage: Cannot read properties of undefined (reading '_page')`. Firefox logs show its tab subprocess could not start. A minimal local `about:blank` check passed only with a local Firefox sandbox override; that override was not added to project configuration. The current full rerun therefore does not establish a fresh three-engine pass, and it does not identify an application assertion failure.

The current measured surface performance run separately passes all 38 comparisons across 19 named production routes and states at 390 and 1440 pixels. The targeted contrast and consumer run passes 36 cases across six browser and viewport profiles. These records prove their enumerated routes, styles, and states, not complete WCAG AA acceptance, all possible product states, visual parity for template art, live provider behavior, or live database behavior.

The selector audit checked each CSS Module imported by a direct shared primitive owner. The preview module adds only spacing to its shared Link; the landing status module styles heading and paragraph descendants; the legal and preview dialog modules style their owned content and typed slots; and editor modules use owner-specific classes around the shared controls. The landing page module also retains unmatched legacy `.navList` and `.footer` selectors, while the live footer module contains no anchor hover rule. No mapped CSS Module declares a shared primitive base, variant, focus, hover, disabled, loading, or error state. Caller utility classes and typed Dialog slots remain explicit. Browser assertions confirm the enumerated composed styles, not every possible prop combination or viewport. The remaining broad accessibility, route and data boundary, and Secret Letter art and motion checks stay open.
